# Data Privacy Checklist

*Print this page. Check off each item as you complete it.*

---

## 🔐 Passwords & Password Manager

- [ ] Install password manager (Bitwarden recommended)
- [ ] Create strong master password (4–6 random words + number + symbol)
- [ ] Save master password in safe place (not digital)
- [ ] Install browser extension + mobile app
- [ ] Import existing passwords from browser
- [ ] Generate new unique passwords for important accounts
- [ ] Enable 2FA on password manager itself
- [ ] Back up recovery kit / emergency sheet

## 🔑 Two-Factor Authentication (2FA)

- [ ] Install authenticator app (Authy, Google Authenticator, or Bitwarden Premium)
- [ ] Enable 2FA on **email** (highest priority)
- [ ] Enable 2FA on **password manager**
- [ ] Enable 2FA on **banking/financial** accounts
- [ ] Enable 2FA on **social media** accounts
- [ ] Enable 2FA on **shopping** accounts (Amazon, etc.)
- [ ] Enable 2FA on **cloud storage** (Google Drive, Dropbox, etc.)
- [ ] Enable 2FA on **work** accounts (GitHub, Slack, etc.)
- [ ] Save backup codes for each account (in password manager)
- [ ] Avoid SMS 2FA where authenticator app option exists

## 🌐 Browser Privacy

- [ ] Switch to privacy browser (Firefox or Brave recommended)
- [ ] Install uBlock Origin
- [ ] Install Privacy Badger
- [ ] Install Cookie AutoDelete
- [ ] Block third-party cookies
- [ ] Enable "Do Not Track"
- [ ] Enable DNS over HTTPS (Cloudflare or NextDNS)
- [ ] Set private search engine (DuckDuckGo or Startpage)
- [ ] Clear browsing data on close (optional)

## 📱 App Permissions

- [ ] **iOS:** Settings → Privacy & Security → review each category
- [ ] **Android:** Settings → Privacy → Permission Manager → review each
- [ ] Set Location to "While Using" not "Always" where possible
- [ ] Revoke Contacts, Microphone, Camera from apps that don't need them
- [ ] Disable "Allow Apps to Request to Track" (iOS)
- [ ] Delete unused apps
- [ ] Review browser site permissions (Location, Camera, Mic, Notifications)

## 🗑️ Data Deletion Requests

- [ ] List accounts you no longer use
- [ ] Submit deletion request to 3+ data brokers (Whitepages, Spokeo, BeenVerified, etc.)
- [ ] Submit deletion request to old services you quit
- [ ] Save confirmation emails
- [ ] Follow up if no response in 2–3 weeks
- [ ] Consider paid service (DeleteMe, Incogni) for ongoing broker removal

## 🤖 AI Privacy

- [ ] Never paste passwords, API keys, or secrets into AI chat
- [ ] Never share SSN, passport, financial, or health data with AI
- [ ] Never share work confidential info / customer data with AI
- [ ] Disable "improve model" / training in ChatGPT settings
- [ ] Use local models (Ollama, LM Studio) for sensitive work
- [ ] Redact sensitive values before pasting code/text to AI

## 🔄 Quarterly Maintenance

- [ ] Review password manager for weak/reused passwords
- [ ] Check 2FA is still enabled on critical accounts
- [ ] Audit phone/app permissions
- [ ] Clear browser data
- [ ] Check for new data broker listings (search your name)
- [ ] Update this checklist

---

## Emergency: If You're Breached

1. **Change password** immediately on breached site + anywhere you reused it
2. **Enable 2FA** if not already on
3. **Check haveibeenpwned.com** for your email
4. **Freeze credit** (US: Equifax, Experian, TransUnion) if SSN exposed
5. **Monitor accounts** for suspicious activity
6. **Report identity theft** at identitytheft.gov (US)
